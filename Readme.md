# Rules

## Played Monopoly before?

### Asymmetric roles: 
- Classic: There is no distinction between players
- Anti-Monopoly: splits players into Competitors and Monopolists

### Start space payout:
- Classic: $200 for passing go 
- Anti-Monopoly: 100 bytes for passing go 

### Rolling doubles:
- Classic: Can roll doubles twice, and go to jail on the third time
- Anti-Monopoly: Can roll doubles once, and go to jail on the second time 

### Pre-requisites for building houses:
- Classic: Need full set of properties to start building houses
- Anti-Monopoly: Competitor can build on a single property without full color set. Monopolist needs 2 in a color to build

### Upgrade threshold 
- Classic: Monopoly needs 4 houses for a hotel universally.
- Anti-Monopoly: Competitor needs 4 houses, Monopolist 3. 

### Even building requirement 
- Classic: can't have an unbalanced number of houses across a set's properties
- Anti-Monopoly: no restriction on house balance 

### Jail 
- Classic: Everyone goes to jail and can collect rent 
- Anti-Monopoly: Prison/Price War, where monopolists go to prison and can't collect rent. Competitors go to price war and can collect rent

### Taxes
- Classic: $200 flat rate
- Anti-Monopoly: 10% of property value + 10% of houses value + 10% of current cash value

### "Free Parking"
- Classic: Empty space 
- Anti-Monopoly: Competitors roll a die and get 25 bytes for rolling a 1 and 50 for rolling a 2. Monopolies need to pay 160 bytes

### Trading 
- Classic: Can make trades at any point
- Anti-Monopoly: Can only make trades on your turn 

### Bailout 
- Classic: Can loan money to players/make special deals
- Anti-Monopoly: cannot loan/make special deals
